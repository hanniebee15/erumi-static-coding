えるみ 日本語版・静的コーディング

■ 制作内容
WordPressで構築するサイトのうち、日本語版の静的コーディングをお願いします。
HTML・CSS・JavaScriptで制作してください。英語版・WordPress構築・CMS組み込みは対象外です。
お知らせ・よみものは仮記事を使用し、ページネーション・フォームは表示までの制作とします。
Dining単独ページは対象外です。
Figma：https://www.figma.com/design/6nzVQS15M5E7ZwbaghTXwD/%E3%81%88%E3%82%8B%E3%81%BFHP?node-id=1245-24655&p=f&t=RhmCLjAMO8bY57Rf-11

■ 支給ファイル
・Bootstrap 5.3.8のCSS・JS、Swiper 14.4.0を同梱しています。モーダルにはBootstrapのJSを使用してください。
・基本設定・カラー・余白などの共通CSSを用意しています。HTML・ページ別CSS・画像は自分で作成してください。
・使用フォントのShippori Mincho・Noto Sans JP・Anonymous ProはGoogle Fontsにあります。利用方法は調べて設定してみてください。

■ CSSの管理
・ヘッダー・フッターなどの共通パーツはassets/css/common.cssへ記述してください。
・ページ固有の指定はassets/css/pages/でページごとに分け、対象ページだけで読み込んでください。お知らせの一覧・詳細はnews.css、よみものの一覧・詳細はblog.cssなどにまとめて良いです。
・読み込み順はBootstrap → common.css → ページ別CSS。SwiperのCSSもページ別CSSより前に読み込んでください。

■ 実装ルール
・読みやすくシンプルなHTML・CSS・JSにしてください。
・Bootstrapのcontainer > row > col-*を基本とし、全幅の要素は必要に応じて外へ出してください。
・モバイルファーストで、PC向けの変更は原則@media (min-width: 992px)で記述してください。390px・1440pxのカンプを基準に、狭いSPやタブレットでも崩れないようにしてください。
・余白はBootstrapのユーティリティ、次にspacing.cssを使用し、足りない指定はページ別CSSに記述してください。上下どちらでもよい要素間の余白はmargin-bottomに揃えてください。
・リンク・ボタンには支給のlink-hoverクラスを使用してください。
・PC/SPで画像を切り替える場合はpictureを使用してください。

■ 画像の準備
・Figmaから原則1.5倍で書き出し、写真はJPG、イラスト・透過表現はPNG、ベクター素材はSVGにしてください。ラスター素材を無理にSVG化しないでください。
・JPG・PNGはTinyPNGで圧縮し、assets/images/内に保存してください。
・画像のファイル名は小文字の英数字を使い、単語の間を「_」等で区切って、ページ・用途が分かる名前にしてください。
・写真やトリミングが異なる場合はPC/SPを分け、無理なく共用できるものだけ共通化してください。文章・見出し・ボタンは画像に含めずHTMLで作成してください。

■ 提出前の確認
各HTMLをブラウザで開き、320px〜1440pxの表示、横はみ出し、メニュー開閉、リンク先を確認してください。
ファイルの参照は相対パスにし、未実装の動作があれば明記してください。

■ デザイン・動作の補足
・TOPは「公開時」のデザインを制作してください。
・TOPのFVは画面の高さいっぱい（100svh）。ローディングアニメーションは最初の一度だけ再生してください。
・ヘッダーは画面上部に固定し、スクロールしても追従させてください。
・ハンバーガーメニューはフェードで開閉してください。
・ご滞在ページのスライダーはSwiperを使用し、ループさせないでください。「詳しく見る」はモーダルで開いてください。
・部屋写真の後ろに敷くぼけた写真は、Figmaのレイヤーブラーを含めて背景用画像として書き出してください。前面の写真とは別にし、CSSでぼかしを重ねないでください。
